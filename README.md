# ✨ Aurora Sign Up Page

A modern and responsive authentication interface featuring a cinematic video background, smooth animations, social login buttons, and an elegant dark-themed design.

## 🚀 Features

- Modern dark UI design
- Responsive layout
- Full-screen video background
- Smooth staggered animations
- Password visibility toggle
- Social login buttons (Google & GitHub)
- Interactive form validation
- Mobile-friendly design
- Built with Tailwind CSS

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6)
- Lucide Icons
- Google Fonts (Inter)

## 📸 Preview

Aurora Sign Up provides a premium authentication experience with:

- Animated hero section
